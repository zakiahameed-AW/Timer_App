# TimerApp

Android Timer App built using Kotlin and Jetpack Compose.

## Screenshot

![Timer App Screenshot](screenshots/timer-app-screenshot.png)

## Project Structure

The project is organized as a standard Android application with the main application code inside the `app` module. The UI is built using Kotlin and Jetpack Compose, while Gradle files manage the project and application build configuration. The project also contains Android Studio configuration files and a `README.md` file that provides an overview of the application. This structure keeps the application source code, build configuration, and documentation organized separately.

## About

TimerApp is a simple Android timer application developed using Kotlin and Jetpack Compose.
